Track your Homey apps directly from Homey.

App Insights for Developers turns each of your published Homey apps into a virtual device with live statistics: install counts (total, cloud and local), live and test version numbers, build state and crashes. Apps of the Developer Organizations you belong to are included as well. Use these values in flows to get a notification when installs grow, when a new version goes live, or when a review fails.

Do you maintain several apps? Add an App overview device per account: one device with the total installs and the installs of every app, plus Flow triggers for any app whose installs go up or down. You choose which of your Developer Organizations it includes.

The App overview also powers six dashboard widgets: App Installs, Install Trend, Recent Changes, Organization Overview, App Spotlight and Milestones.

Setup requires a Personal Access Token from your Athom developer account. See the in-app settings or the online documentation for step-by-step instructions.
