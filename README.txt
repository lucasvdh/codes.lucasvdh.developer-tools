Track your Homey apps directly from Homey.

App Insights for Developers turns each of your published Homey apps into a virtual device with live statistics: install counts (total, cloud and local), live and test version numbers, build state and crashes. Use these values in flows to get a notification when installs grow, when a new version goes live, or when a review fails.

Setup requires a refresh token from your Athom developer account. See the in-app settings or the online documentation for step-by-step instructions.

This is an independent community app and is not affiliated with or endorsed by Athom.
