Verfolgen Sie Ihre Homey-Apps direkt von Homey aus.

App Insights for Developers macht aus jeder Ihrer veröffentlichten Homey-Apps ein virtuelles Gerät mit Live-Statistiken: Installationszahlen (gesamt, Cloud und lokal), Live- und Testversionsnummern, Build-Status und Abstürze. Apps der Developer Organizations, in denen Sie Mitglied sind, werden ebenfalls berücksichtigt. Verwenden Sie diese Werte in Flows, um benachrichtigt zu werden, wenn die Installationszahlen wachsen, eine neue Version live geht oder ein Review fehlschlägt.

Sie pflegen mehrere Apps? Fügen Sie pro Konto ein App-Übersicht-Gerät hinzu: ein Gerät mit den Gesamtinstallationen und den Installationen jeder App, plus Flow-Auslöser für jede App, deren Installationszahl steigt oder sinkt. Sie wählen selbst, welche Ihrer Developer Organizations einbezogen werden.

Die App-Übersicht liefert auch die Daten für sechs Dashboard-Widgets: App-Installationen, Installationstrend, Letzte Änderungen, Organisationsübersicht, App im Fokus und Meilensteine.

Für die Einrichtung wird ein Personal Access Token Ihres Athom-Entwicklerkontos benötigt. Eine Schritt-für-Schritt-Anleitung finden Sie in den App-Einstellungen oder in der Online-Dokumentation.

Dies ist eine unabhängige Community-App und steht in keiner Verbindung zu Athom.
